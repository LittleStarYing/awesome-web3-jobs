# Contribution Guidelines

Thanks for your interest in contributing. Please make sure your pull request adheres to the following rules:

## What belongs on this list

- **Active, maintained resources.** If the site has not been updated in 12+ months, it does not belong here.
- **Useful to job seekers.** Every entry should help someone find, prepare for, or land a web3 / crypto job.
- **Primary-source links.** Link to the official company careers page, not a secondary listing.
- **Global in scope or clearly labeled regional.** If a resource is only for a specific country, note that.

## What will be rejected

- Dead or broken links.
- Paid services presented as free.
- Self-promotion without adding value.
- Scam or obviously fraudulent projects.
- Resources unrelated to hiring, career development, or compensation.

## Formatting

- Follow the existing format — link, em-dash, one-line description, optional emoji tag.
- Alphabetize within sections (except the headline entry in "Job Boards" which intentionally leads the list).
- Use sentence case for descriptions.
- Do not add trailing periods unless the description is a full sentence.

## Pull Request

- Add your entry in a single commit if possible.
- In the PR description, explain in one sentence why the resource deserves inclusion.
- Do not bundle unrelated changes.

## Code of Conduct

Be decent. No spam, no harassment, no hateful content. The maintainers reserve the right to close or block bad-faith contributions.
